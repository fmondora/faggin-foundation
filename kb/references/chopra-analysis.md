# Analisi: deepakchopra.com — Stile Narrativo

## Cosa fa bene (da replicare)

### Hero personale
- Foto ritratto full-bleed di Chopra
- Testo biografico sovrapposto con backdrop blur
- Announcement bar in alto (meditazione in corso)
- Header che alterna light/dark in base alla sezione

### Carousel featured
- Auto-rotazione 7s con pause-on-hover
- Contenuti misti: corsi, libri, AI, meditazione
- Transizioni fluide tra card

### Struttura verticale narrativa
1. Welcome/Hero (chi sono)
2. Featured carousel (cosa offro ora)
3. Book showcase (ultimo libro grande)
4. AI platform (innovazione)
5. Newsletter (connessione continua)
6. Footer

### Layout tecnico
- Grid 24 colonne desktop / 8 mobile
- Gap 11px, padding 2vw desktop / 6vw mobile
- Fade-in globale: 1.5s duration, 0.6s delay
- Header "Scroll Back": appare/scompare in base alla direzione

### Cosa adattare per Faggin
- Ritratto Chopra → foto/video di Federico
- Corsi → Video Serie
- AI platform → sezione Coscienza e IA
- Meditazione → citazione del giorno
- Newsletter → già presente nel footer
- Avatar AI (chopra.ai) → possibile futuro chatbot Faggin?

## Pattern chiave
```
[Ritratto + bio] → [Carousel highlights] → [Libro in evidenza] → [Messaggio chiave] → [Newsletter]
```
Scroll verticale classico. Il visitatore scorre una narrazione. Il protagonista è la persona.
